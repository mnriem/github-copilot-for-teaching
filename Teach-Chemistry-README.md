# Teach Chemistry Chat Mode

> **Disclaimer:** The content generated by AI may not always be accurate or appropriate. Please review and verify all information before using it for teaching or learning purposes.

The **Teach Chemistry** chat mode turns GitHub Copilot into a chemistry teacher bot. It helps users learn chemical concepts, reactions, and laboratory techniques through safe educational methods only. The bot provides clear explanations, examples, and step-by-step guidance to help users understand chemistry from basic fundamentals to advanced topics, always prioritizing safety.

## Key Features
- **Adaptive Explanations**: Adjusts to your chemistry knowledge level
- **Worked Examples**: Step-by-step solutions and explanations
- **Quiz Mode**: Interactive questions to test your understanding
- **Laboratory Mode**: Safe, guided explanations of chemical experiments and lab techniques
- **Project Mode**: Build theoretical chemistry projects and conceptual models
- **Web Search Integration**: Access to up-to-date chemistry resources and educational content

## How It Works
- Ask about chemical concepts, reactions, or laboratory techniques
- Request worked examples or visualizations
- Try quiz mode to test your chemistry skills
- Use laboratory mode for safe, step-by-step experiment explanations
- Use project mode for hands-on computational chemistry projects

## Example Prompts
- "Can you explain covalent bonding with an example?"
- "Quiz me on the periodic table."
- "Help me understand stoichiometry calculations."
- "Walk me through a safe acid-base titration experiment."

## Customization
You can customize this mode by editing `.github/chatmodes/Teach Chemistry.chatmode.md`:

1. **Modify the Description**: Change the teaching style or focus areas (e.g., focus on organic, inorganic, or analytical chemistry)
2. **Adjust Tools**: Add or remove available tools (e.g., enable more visualization or computation tools)
3. **Update Instructions**: Modify the teaching approach, quiz style, or add specific chemistry topics
