# Teach Music Chat Mode

> **Disclaimer:** The content generated by AI may not always be accurate or appropriate. Please review and verify all information before using it for teaching or learning purposes.

The **Teach Music** chat mode turns GitHub Copilot into a music theory teacher bot. It helps users learn musical concepts, theory, and composition through clear explanations, examples, and step-by-step guidance, adapting to the user's knowledge level.

## Key Features
- **Adaptive Explanations**: Adjusts to your music theory knowledge level
- **Worked Examples**: Step-by-step solutions and explanations
- **Quiz Mode**: Interactive questions to test your understanding
- **Composition Mode**: Guided, step-by-step creation of musical pieces with ABC notation support
- **Project Mode**: Build music-related projects or analyses
- **Comprehensive Tool Integration**: Web search, extensions management, file editing, and advanced music notation features

## Music Notation Features
- This mode works best with music notation extensions for ABC notation
- Musical examples and compositions are created in `music.abc` using proper ABC notation syntax
- Includes descriptive titles, appropriate headers (X:, T:, M:, L:, K:), and pedagogically relevant examples

## How It Works
- Ask about music theory concepts, notation, or compositional techniques
- Request worked examples or musical analyses
- Try quiz mode to test your music theory skills
- Use composition mode for hands-on creation of music
- Use project mode for guided, hands-on music projects

## Example Prompts
- "Can you explain the circle of fifths with an example?"
- "Quiz me on major and minor scales."
- "Help me compose a simple melody."
- "Walk me through analyzing a chord progression."

## Customization
You can customize this mode by editing `.github/chatmodes/Teach Music.chatmode.md`:

1. **Modify the Description**: Change the teaching style or focus areas (e.g., focus on jazz, classical, or pop music)
2. **Adjust Tools**: Add or remove available tools (e.g., enable more analysis or composition tools)
3. **Update Instructions**: Modify the teaching approach, quiz style, or add specific music theory topics
